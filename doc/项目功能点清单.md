# 项目功能点清单（多租户与权限系统）

- 整理对象：`concise-server-node`（NestJS 后端）
- 整理日期：2026-11-21
- 范围：`src/modules` 全部业务模块、全部 V1 控制器、多租户基础设施、权限系统、通用工具模块
- 说明：所有接口实际带全局前缀 `/api`（`src/main.ts`：`app.setGlobalPrefix('api')`），下文直接写成 `/api/...`
- 规模：16 个业务模块、38 个控制器、约 220+ 条接口；除 `@Public`（登录/验证码/SSO/刷新/健康检查/开放令牌）外全部默认 JWT 鉴权

| 13 | `customer` | `customer.v1.controller.ts` | 客户（带 owner 数据范围） |
| 14 | `biz_order` | `biz_order.v1.controller.ts` | 订单（带 owner 数据范围） |
| 15 | `supplier` | `supplier.v1.controller.ts` | 供应商 |
| 16 | `health` | `health.controller.ts` | 健康检查（DB + Redis） |

另有 `src/app.controller.ts`（公开健康检查）、`src/shared/*`（tenant / permission / permission-cache / auth-cache / audit / rate-limit / redis / totp / storage / mailer / backup / realtime / logger 等基础设施）。

**全局机制**（`src/app.module.ts`）：
- 全局守卫顺序：`RateLimitGuard → JwtAuthGuard → RolesGuard → PermsGuard → ApiScopeGuard`
- 全局拦截器：统一响应包装 + 操作日志；全局异常过滤器
- 租户中间件 `TenantMiddleware` 挂到所有路由（`forRoutes('*')`）

> 事实提醒：代码中**没有任何接口实际声明 `@Roles()`**（全库搜索仅命中注释/DTO/实体）；角色守卫已注册但当前未使用。`@ApiScope` 仅用于开放接口 2 条。
